## Project Overview

Repair Workshop Queue is a desktop application for managing repair customers,
devices, jobs, estimates, job history, and warranties.

## Technology

- Language: Java
- User interface: Swing
- Database: PostgreSQL
- Database access: JDBC thuần (PostgreSQL JDBC driver, không dùng Maven; biên dịch bằng `javac`)
